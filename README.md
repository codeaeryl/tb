HOW TO USE ADMIN APP:
1. Install XAMPP "https://www.apachefriends.org/download.html"
2. You need **php** to run the project **(PHP ver 8.2.12 is what we're using)**
3. You need to **install dependency** using **composer install**
3. Run **Apache and MySQL services** on XAMPP.
4. Go to **<project_root>/app/database/db.sql** for the database query
5. Open MySQL Admin (phpMyAdmin) on Browser
6. Execute the query inside the **db.sql**
7. Open new browser tab.
8. To access the app, open with live server and the app main interface is on **<project_root>/app/public/index.php**.
    Example: "http://localhost:63342/tb/public/index.php"
